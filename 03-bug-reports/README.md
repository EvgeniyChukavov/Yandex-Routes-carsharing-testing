# Баг-репорты

## Описание
Задокументированы баги, найденные в ходе тестирования каршеринга в Яндекс Маршрутах: вёрстка, оплата, логика кнопки «Забронировать».

## Что сделано
- Найдено 30 багов
- Задокументированы шаги воспроизведения, ожидаемый и фактический результат
- Указан приоритет каждого бага
- Приложены скриншоты

## Инструменты
- Яндекс Браузер (800×600)
- Firefox (1920×1080)
- Google Таблицы

- Стандартные: 5
- Желательные: 21
