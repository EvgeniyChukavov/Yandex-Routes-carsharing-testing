# Тест-кейсы

## Описание
Созданы тест-кейсы на проверку логики кнопки «Забронировать» в каршеринге Яндекс Маршрутов.

## Что проверялось
- Логика кнопки при заполнении всех обязательных полей
- Логика кнопки при отсутствии прав
- Логика кнопки при отсутствии способа оплаты
- Логика кнопки при отсутствии адресов «Откуда» и «Куда»

## Инструменты
- Firefox (1920×1080)
- Google Таблицы
