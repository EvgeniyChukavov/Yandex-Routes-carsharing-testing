# Тестирование каршеринга в Яндекс Маршрутах

## О проекте
Проведено тестирование функциональности каршеринга в веб-приложении Яндекс Маршруты: вёрстка формы бронирования, окна «Способ оплаты» и «Добавление карты», логика кнопки «Забронировать».

**Яндекс Маршруты** — это сервис, который строит маршруты для транспорта разных видов, рассчитывает время и стоимость поездки. В текущей версии добавлена возможность заказать каршеринг.

## Что тестировалось
- **Вёрстка формы бронирования** — тарифы, кнопки, дополнительные параметры
- **Форма «Добавить права»** — состояния, иконки, текст
- **Форма «Способ оплаты»** — окна «Добавление карты», валидация полей
- **Форма «Требование к заказу»** — чек-боксы, разделители
- **Кнопка «Забронировать»** — логика работы при разных состояниях полей
- **Окно «Машина забронирована»** — вёрстка, разделители, данные
- **Окна отмены брони** — «Вы уверены?», «Поездка отменена»
- **Навигационная карта** — иконки машин, выбор тарифа

## Инструменты
- Яндекс Браузер (800×600)
- Firefox (1920×1080)
- Google Таблицы — ведение чек-листов, тест-кейсов, баг-репортов
